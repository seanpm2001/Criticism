# Criticism

"When you use the Internet, you have to expect that someone will criticize you." - [:octocat: `Inverno4`](https://github.com/Inverno4/)

Criticism is a normal part of life. This repository is for documenting criticism.

I only accept constructive criticism. If you give criticism, such as "you suck" without giving a reason why, I will not accept it.
